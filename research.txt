## PS3 Bluetooth 3rd Party Headphones - Rebug 4.84.2

Target: Rebug 4.84.2 (Cobra 8.1). Goal: Allow 3rd party BT headphones (e.g. Bose QC35, QC35II, QC45, Sony WH-1000XM3/4, generic A2DP) to pair/connect properly (audio routing).

## Key Concepts
- PS3 uses Sony's Bluetooth stack - heavily restricted to "officially supported" profiles/devices (headset profile HSP/HFP, some A2DP implementations). Many modern ANC headphones don't pair or don't get A2DP audio properly.
- Cobra/Mamba on CFW can patch system modules. Evilnat added expanded BT device support in newer builds - people want similar for Rebug 4.84.2.
- Possible approaches: replace/patche bluetooth libraries (bluetooth.sprx, btlib.sprx?), patch bd_addr restrictions, patch device class/profiles, add A2DP sink compatibility.
- Plugins: .sprx loaded via boot_plugins.txt (Cobra) or Rebug Toolbox plugins.

## Notes
- A2DP support on PS3 is finicky. Some headphones connect but audio doesn't route; others refuse pairing.
- Audio output must go to BT device - AV settings/Bluetooth device management.
## Practical research notes (what to look for)

### What likely enables 3rd party BT on newer CFW (Evilnat)
- Modified bluetooth firmware/module patches - whitelist/compat list removed
- Patches to allow A2DP (stereo) for more devices
- Device class/protocol handling - many modern BT headsets use different SDP/HFP/A2DP versions
- Rebug 4.84.2 has Cobra 8.1 but BT handling may be more restrictive vs newer Evilnat builds

### Potential module targets (to reverse engineer)
From PS3 firmware: 
- /dev_flash/sys/internal/bluetooth.sprx (or similar)
- /dev_flash/sys/external/libbt.sprx
- Related to bt service, maybe brcm/broadcom BT chip
- Audio routing: audio modules may also need patching for BT output

### Plugin approach
- Create small .sprx plugin (Cobra compatible) loaded at boot via boot_plugins.txt
- Hook functions in bluetooth stack to bypass device compatibility checks
- Package as .pkg if we want installer? Or just provide sprx + instructions

### Existing work to check
- webMAN MOD doesn't focus on BT headset compatibility
- Some community patches exist (e.g. "Bluetooth Headset Fix" type mods)
- Look for differences between Rebug 4.84.2 and Evilnat BT code
